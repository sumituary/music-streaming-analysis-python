# Music Streaming Analytics Dashboard 

## Project Overview

This project explores music streaming platform metrics over a six-month period using Python.

The goal is to analyze trends in songs played, active users, premium subscribers, listening hours, revenue, playlists, new users, and likes through data analysis and visualizations.

## Tools & Libraries Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset

The dataset contains six months of fictional music streaming metrics, from January to June.

It includes:
- Songs Played
- Active Users
- Premium Subscribers
- Listening Hours
- New Playlists
- New Users
- Revenue
- Likes

**Note:** This is a synthetic dataset created for learning and practice with help of  AI assistance. It does not represent real music streaming platform data.

## Dashboard Visualizations

The project includes 8 visualizations:

1. Songs Played Trend
2. Monthly Active Users
3. New Users Growth
4. Listening Hours Trend
5. Monthly Revenue
6. Likes Trend
7. Active Users vs Premium Subscribers
8. Songs Played vs Likes

## Key Analysis

The notebook explores:
- Total songs played
- Average active users
- Total listening hours
- Total revenue
- Average likes
- Months with the highest songs played, active users, revenue, and listening hours
- Overall trends in platform activity and engagement

## How to Run

1. Download or clone this repository.
2. Install the required libraries:

   `pip install pandas matplotlib jupyter`

3. Open the notebook using Jupyter Notebook.
4. Run the notebook cells to generate the dashboard and analysis.
